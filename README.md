# NBA 编辑工作台（NBA Editorial Content Generation Platform）

面向体育编辑的一站式 NBA 内容生产工具：自动写文案、查球星历史数据、盯当日比分与新闻。

**在线访问（GitHub Pages）**：https://eatonz3927.github.io/NBA-Editorial-Content-Generation-Platform/

## 架构：纯前端 BYOK

本应用为**纯静态站点**，无需任何后端 / 数据库，可直接部署到 GitHub Pages：

- **数据来源**：比分、新闻、联盟数据榜、球员档案与生涯数据均由访问者的浏览器**直连 ESPN 公开接口**获取（CORS 开放），缓存落在各自浏览器的 localStorage。
- **AI 文案生成（BYOK）**：首次打开会引导填入自己的 **阿里云 DashScope API Key**（默认模型 deepseek-v4.1-flash-1017，支持更长的 `sk-ws-` 新版密钥）。Key 仅保存在当前页面内存中，不写入 sessionStorage/localStorage，刷新、关闭标签页或离开本站后需重新填写，站内切换页面可继续使用；离开文档时还会清空内存引用。旧版浏览器存储中的密钥会尝试移除。页面恶意脚本或浏览器扩展仍可能读取使用中的密钥。生成时浏览器通过 HTTPS 直连 DashScope，不经过中转服务器；禁止通过公开环境变量打包统一密钥。
- **草稿箱**：保存在本浏览器 localStorage，每个使用者各自一份。

## 功能

| 模块 | 说明 |
| --- | --- |
| 🏀 比分中心 | 按北京时间自然日查看比分，直播每 30 秒刷新，未开赛及刚结束的比赛每分钟更新；支持强制刷新、真实更新时间与失败提示 |
| 📊 比赛详情 | 逐节比分、14 项球队数据对比、焦点球员、双方 boxscore；直播每 30 秒刷新，未齐全的统计每分钟补抓，连续失败或缺统计最多自动重试五次 |
| 📰 新闻中心 | 每 12 小时自动抓取 ESPN 最新新闻（北京时间 0/12 点边界），保留最近 10 天，支持手动刷新（仅当前页面预览），可「改写成快讯」 |
| 🔎 球星检索 | 中英文搜索，球员档案、分赛季数据（常规赛/季后赛）、生涯汇总、近期出场、荣誉 |
| ✍️ 文案工作台 | 比赛比分 / 球员数据 / 新闻素材自由组合，9 种文体 × 5 种语气 × 3 种篇幅，AI 生成（未配置 Key 时回退本地模板引擎） |
| 🗂️ 草稿箱 | 本地保存、展开、复制、删除 |
| 🌗 日间/夜间 | 按本机时段默认（9:00–18:00 日间），可随时手动切换并记住选择 |

## 本地开发

```bash
npm install
npm run dev        # http://localhost:3000
npm run test:scores # 日期、缓存、请求失败、赛程回退及详情补齐的回归检查
npm run test:players # 赛季滚动、新赛季汇总延迟、逐场兜底和缓存的回归检查
```

比分查询覆盖目标北京时间日期对应的相邻 ESPN 比赛日，再按开赛时间筛选、去重。
默认进入比分中心时，今天没有比赛会回查最近三天，再利用 ESPN 单日响应里的赛程日历定位更早比赛。
切回前台或网络恢复时会强制更新；网络失败保留旧缓存并明确提示，不会当作“无比赛”。
缓存按比赛状态和统计完整度设置有效期；升级后的比分与详情缓存使用新版本键，旧缓存不再读取。

球员统计统一以赛季起始年为应用口径，请求 ESPN 时转换为结束年（如 2026-27 → 2027），每年自动滚动。
每次更新直接探测当季常规赛汇总，不依赖生涯赛季目录是否已更新；汇总缺失或场次落后时，
按指定赛季的常规赛逐场记录汇总，并在页面标注“逐场汇总”。命中率使用总命中/总出手，排除季前赛与重复赛事；
官方汇总场次追上后优先使用官方数据。概览接口可能忽略赛季参数，因此不能据此认定当季统计。
球员页面每 5 分钟更新当季数据，尚未发布时每分钟重查，支持强制刷新；历史赛季独立缓存 24 小时。
这些更新在打开应用时执行，静态网站关闭后不会后台抓取。

## 部署到 GitHub Pages

一条命令完成构建 + 发布（仅发布静态文件到 `gh-pages` 分支，保留分支历史，不强制推送）：

```bash
bash scripts/deploy-pages.sh
```

首次使用需在仓库 **Settings → Pages → Source** 选择 **「Deploy from a branch」**，Branch 选 **`gh-pages` / (root)**。

构建时通过环境变量 `PAGES_BASE_PATH=/<仓库名>` 注入子路径前缀（项目页路径）；本地开发无需设置。之后每次改动代码，重新运行上面的脚本即可更新线上页面。

仅验证构建和发布提交、暂不推送：`bash scripts/deploy-pages.sh --prepare-only`。发布源码时只选择本次修改文件，不要将本地输出目录或任何密钥文件加入提交。

## 给编辑同事使用

1. 打开 Pages 地址；
2. 首次进入会跳转到「密钥设置」页，填入 DashScope Key（[阿里云百炼控制台](https://bailian.console.aliyun.com/?apiKey=1#/api-key) 免费获取）；
3. 比分 / 新闻 / 球员数据浏览无需 Key；仅「生成文案」需要。
